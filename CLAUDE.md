# Visual Site Builder

- Перед работой прочитай `PRD.md`, `SPEC.md` и `TASKS.md`.
- Выполняй только запрошенный sprint из `TASKS.md`; не реализуй функции следующих спринтов заранее.
- После спринта отметь выполненные checkbox в `TASKS.md` и прогони `npm run typecheck` и `npm run build`.
- Editor меняет Page JSON → Block Registry → PageRenderer строит UI (SPEC §2). Не хардкодить блоки в Canvas.
